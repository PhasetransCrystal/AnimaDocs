# AnimaDocs 首页 Hero 主题切换动效 · 开发规格

- 站点：https://anima.ptcrys.net/
- 基线：`e34a7ea`（参见 launch-orbit-brief.md）
- 设计基础：lanart-alpha-v1 + `references/case-study-animadocs.md`
- 范围：仅首页 hero（日→夜“升空入轨”、夜→日“着陆”）+ hero 内高度计。文档页高度元素延后，本期不做。
- 状态：设计已定稿，进入原型阶段；第 11 节为需原型验证后回传的参数。

## 1. 硬性约束

- 不修改、不暂存 `website/docs/**`、`website/sidebars.ts`、`website/static/**`。
- 不破坏 `useHeroPaging`（滚轮/键盘吸附、`.heroArt[data-art-paused]`、最大 120px 的 translateY）。
- 保留现有 `clientModules/themeTransition.ts` 的 VT 与 `theme-transitioning` 回退路径，作为非 hero 场景的默认切换。
- `prefers-reduced-motion: reduce` 下直接切换，不播放任何本规格动画。
- 遵守 DESIGN_ASSETS.md “实现约定”：装饰确定性生成、`aria-hidden`，正文不加装饰，可读性不下降。
- 不新增全局色层/大气色带；黑白切换只通过以板面圆心为中心的圆形裁剪完成。

## 2. 叙事与端点

- 日→夜：日间底板整体收缩，最终变成夜间那颗白色小星球；随后红星与主轨道“入轨”落位。
- 夜→日：白色小星球扩张，长回日间底板；方块阵列与海洋块依次浮现。
- 两个方向是同一个物体的正反过程，圆形裁剪的终点/起点半径 = 白星半径。

| 端点 | viewBox 坐标（1440×900） | 说明 |
| --- | --- | --- |
| 日间 | (640, 150) | 左侧大引导圆中心（r170，36 刻度） |
| 夜间 | (606, 198) | 轨道环左侧白色小星球（带脉冲环） |

坐标换算（SVG 为 `xMidYMin slice`）：

```ts
const s = Math.max(w / 1440, h / 900);   // w,h 为 .heroArt 的 CSS 尺寸
const ox = (w - 1440 * s) / 2;           // 水平居中裁切
const oy = 0;                            // 顶部对齐
const toPx = (x: number, y: number) => ({ x: ox + x * s, y: oy + y * s });
// 若使用视口坐标，再加上 .heroArt 的 getBoundingClientRect() 偏移（含 useHeroPaging 的 translateY）
```

动画中心需在两端点间插值（演员层 T1 平移阶段完成），裁剪圆心以夜间端点为准。

## 3. 触发与交互规则

| 条件 | 行为 |
| --- | --- |
| reduced motion | 直接切换，无动画 |
| 跟随系统主题变化 / 标签页不可见 | 直接写入终态 |
| 桌面，hero 可见（未被 useHeroPaging 翻走） | 播放第 6/7 节完整动画 |
| 手机（≤640px），hero 可见比例 ≥ 0.5（IntersectionObserver） | 播放第 8 节简化动画 |
| 其它情况 | 沿用现有缓存图像淡化（VT / 回退） |

- 动画期间禁止二次输入：主题按钮设 `aria-disabled="true"`，拦截 click 与 keydown（Enter/Space）。不使用 `disabled` 属性，避免焦点丢失。
- 动画期间暂停 hero 吸附（复用 `data-art-paused` 逻辑），滚轮/键盘不翻页。
- 看门狗：总时长 + 400ms 后强制写入终态、解锁、恢复吸附，防止 animationend 丢失导致永久锁定。
- 动画中切到后台（`visibilitychange`）：立即写入终态。
- 推荐用 WAAPI 统一驱动：一个控制器持有所有 `Animation`，以 `Promise.all(anims.map(a => a.finished))` 收尾。

## 4. 分层架构

自下而上：

| z 序 | 层 | 内容 | 动画允许的属性 |
| --- | --- | --- | --- |
| 1 | 夜间布景层 | 夜间底板拆为：①背景+淡网格 ②颗粒/模糊滤镜组（FOCUS 盘、terraces） ③其余元素（像素闪烁、加号等） | 整层 opacity |
| 2 | 色层 | 一个 `border-radius:50%` 的 div，实色（日→夜红 / 夜→日钴蓝→浅蓝） | transform: scale、background-color |
| 3 | 日间布景层 | 日间底板拆为：①海洋块+方块网格 ②线条+标注+路线 ③引导圆 | 整层 opacity/transform；整个日间容器承载圆形裁剪 |
| 4 | 演员层 | 轻量叠加 SVG（无滤镜），坐标与底板一致 | 内部元素自由动画（元素数量少） |
| 5 | 高度计 | DOM，位于 `.heroArt` 之外的内容列中 | transform、opacity、color |

- 动画期间两张底板同时挂载；动画结束后卸载非当前底板，恢复 `display:none` 机制。
- 非当前底板在 T0 挂载（`opacity:0`），用 T0 的轻量动画掩盖约 70–90ms 主线程占用。
- 演员层接管的原件（引导圆、白星、主轨道、红星）在动画期间于底板中隐藏，结束时换回原件，位置必须像素对齐。
- 演员层元素：环、3 个蓝边小方块、3 条蓝线、3 条红线及末端小圆、坐标轴（原点方框/十字、刻度线、里程碑名称）、白点、红星替身（平涂圆）、主轨道替身（单个椭圆描边）。
- 所有装饰 `aria-hidden="true"`；随机分组使用现有 LCG（种子沿用 20260816 或新增固定种子），保证截图可复现。

## 5. 高度计

### 5.1 位置与语义

- 仅首页 hero，桌面放在左侧标题上方空白处（删除日间“01”标记）。
- 放在 `.heroArt` 之外，不随 useHeroPaging 位移。
- 语义：

```html
<div class="altimeter">
  <p class="altimeter__reading">
    <span class="sr-only">当前高度：325 米（地面发射场）</span>
    <span aria-hidden="true" class="altimeter__value">325</span>
    <span aria-hidden="true" class="altimeter__unit">m</span>
  </p>
  <p aria-hidden="true" class="altimeter__place">地面发射场</p>
  <div aria-hidden="true" class="altimeter__scale"><!-- 刻度带 + 速度条 --></div>
</div>
```

- sr-only 文本只在终态更新一次，不随滚动数字播报。

### 5.2 桌面形态

- 左：竖向刻度带 + 与之平行的速度实心条；右：上方小字高度数字，下方大字地点。
- 刻度带：重复刻度图案，仅 `translateY` 滚动，位移按对数高度映射。
- 速度条：读数 = d(log 高度)/dt。零点位于刻度高度约 70%（中间偏下），零点以下约 20% 为减速区（使用另一颜色）。
  - 升空：自零点向上生长，入轨时滑入减速区后归零。
  - 着陆：前半向上，后半进入减速区后归零。
  - 非动画状态为 0，不显示。
- 数字渐变：仅数字 span 使用 `mask-image` 上→下渐淡（形成半遮挡感），大字地点不渐变。遮罩随数字 scale，比例不变；颜色单独用 `color` 过渡。
- 动画态：大字淡出；数字平移到刻度竖直中心并放大约 1.8 倍（`transform`，禁止动画 font-size）；结束后缩回，大字淡入。小字/大字使用绝对定位叠放，避免重排。

### 5.3 手机形态

- 仅高度数字 + 下方横向小刻度条。
- 地面：刻度条为刻度线；高空：刻度条下半部填实。过渡中横向滚动，结束后 300ms 淡出。

### 5.4 数值与格式

- 范围：325 m → 799,000 km，对数插值。
- `font-variant-numeric: tabular-nums`；滚动中保留 3 位有效数字；1,000 m 处换单位（999 m → 1.00 km）。
- 里程碑（刻度带节点 / 演员层坐标轴名称 / 颜色分段）：

| 高度 | 名称 | 数字颜色 |
| --- | --- | --- |
| 325 m | 地面发射场 | 日间文字色 |
| 10 m / 1 km | 低空 | 待定 |
| 100 km | KÁRMÁN | 待定 |
| 36,000 km | GEO | 待定 |
| 384,400 km | MOON | 待定 |
| 799,000 km | 高空轨道 | 夜间文字色 |

- 坐标轴只显示里程碑名称，数字只出现在高度计中，避免同屏两套数字。

## 8. 手机端（≤640px，约 800ms）

- 不锚定星球/环；过渡圆从视口顶部中央发散。手机无滚动吸附，触发判定见第 3 节。
- 流程：
  1. 0–180ms：当前底板整层淡出，只保留低透明度元素。
  2. 调用 `startViewTransition`，回调内切换主题；新状态底板初始 `opacity:0`。
  3. `::view-transition-new(root)` 以 `clip-path: circle(0 at 50% 0)` → `circle(<到最远角距离> at 50% 0)` 展开，约 600ms，cubic-bezier(.6,0,.3,1)；`::view-transition-old(root)` 静止在下层，关闭默认淡化。
  4. new 伪元素为实时渲染，高度数字与横向刻度条在圆内持续动画；约 450ms 起新底板元素淡入。
  5. 刻度条结束后 300ms 淡出。
- 不支持 VT 的浏览器：走现有 `theme-transitioning` 回退。

## 9. 性能约束

- 布景层只允许整层 `opacity` / `transform` / 圆形裁剪；不对 SVG 内部大量子元素逐个做动画。
- 方块网格：种子分 6–8 组，每组单次 steps 切换，禁止每块独立动画。
- 夜间颗粒（feTurbulence）与模糊滤镜在动画开始即关闭，结束前作为整层恢复；动画主过程不得包含滤镜重绘。
- 红星缩放使用无滤镜平涂替身，落位后与真身交叉淡化。
- 色层使用 div + `transform: scale`，不动画 width/height/r。
- 裁剪：先试 `clip-path: circle()` 的 WAAPI 动画；若 4x CPU 降速下中段掉帧，退回 rAF 写 clip-path（被裁剪对象始终是较轻的日间底板）。
- 高度计数字使用 transform 缩放，不动画 font-size；数字文本更新节流到每帧一次。

## 10. 验收

- 性能：Chrome Performance 面板 4x CPU 降速，双向各录制一次；单个长任务 ≤ 50ms（T0 挂载除外，需被 T0 动画掩盖），裁剪中段无连续掉帧。
- 截图：手机 / 桌面 / 宽屏三个视口，双向各取 4 帧：0ms、曲线超越点、主题切换点、终态。终态需与当前线上静态底板一致。
- 对齐：演员层换回原件时无可见跳动（引导圆、白星、主轨道、红星像素对齐）。
- 边界：快速连点、键盘 Enter/Space、动画中滚轮、切到后台标签页、reduced motion、系统主题变化，均不出现卡锁或中间态残留。
- 无障碍：主题按钮焦点不丢失；高度计 sr-only 只在终态更新；装饰均为 `aria-hidden`。
- 无横向滚动；hero 吸附在动画前后行为不变。
- typecheck / build 通过。
