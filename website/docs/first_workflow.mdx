# 第一个工作流：标准文生图

本章节将带大家大致了解comfyui的操作方式，讲解最基础的图片生成原理，并产出第一张ai图片——画风可能很简陋，但不用担心，这些都可以调整！

## ComfyUI基本操作方式

讲的比较碎，自己琢磨琢磨可能懂的更快？如果已经搞懂了可以直接跳到[基本生图流程](#基本生图流程)部分。

打开cui，你大概可以看到这样一个画面：

![cui主界面](/img/docs/first_workflow/cui_1.png)

根据常用程度将其划分为了五个部分，文字和框的颜色相对应：

- 工作流分页：cui允许用户同时打开多个工作流，各个工作流之间互不影响。点击这里的选项卡可以切换到其它工作流，最右侧的"+"可以创建一个新的空白工作流。
  在cui被关闭时，工作流分页仍会被保留，无需每次启动都打开工作流。按下分页右侧的x号可以关闭该工作流，这一过程不会删除工作流文件本身。
- 节点选择区：左侧侧边栏最常用的功能，按下“节点”按钮后弹出。这个界面包含comfyui所有的官方或第三方节点。
  展开文件夹，点击或拖拽一个节点到工作流区域，即可将节点添加至工作流。另外，节点条目最右侧的书签标记点击后，列表最顶部会将其加入收藏，便于快捷使用。
  最顶部的搜索框同样可以帮助您快速找到需要的节点。
- 主工作流区：这里是你的工作流展示区域，也是整个cui的核心功能所在。在这里搭建的工作流，运行时程序会自动根据流程执行任务，产出内容。下面会详细介绍如何使用。
- 节点信息界面：用的较少。隐藏状态下点击运行工具栏最右边按钮展开，可以详细看到节点的数值内容，功能文档，以及状态等。
